## Uncertainty and decisions

Each independent statistical unit is a run/block, not an individual message. Report all five observations, median/min/max and raw distributions. Pair policies by predeclared adjacent block; report each paired absolute difference, ratio and percent effect. Use exact ordered block bootstrap: all5^5=3125 resamples of the five blocks, preserving cross-policy pairing; percentile2.5/97.5 nearest-rank intervals. For pooled quantiles, resample whole run cohorts and recompute the pooled endpoint, not an iid message bootstrap. For rates/RPC/idle use ratios of resampled means and mean paired differences. For recovery differences use uncensored complete pairs only if **all five pairs** recover; otherwise report censoring and no falsely complete recovery CI. These are descriptive small-n bootstrap intervals, not calibrated guarantees, significance tests or evidence of host/population generality. No iid-message CI, outlier trimming, p-value fishing or post-hoc endpoint selection.

H1: supported in measured runs only if all safety/lifecycle checks pass; any violation falsifies.
